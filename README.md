## Project Overview
This website is for Gogas Stationery. It is a small shop that sells books, stationery, etc. The website provides important information about the shop to customers.

# Key Features
- Homepage
- About Us
- Services (Products)
- Enquiry
- Contact

# Part 2 Updates: CSS Styling and Responsive Design
- Created an external CSS stylesheet (`style.css`) and linked it to all HTML pages.
- Applied base styles, typography, and a CSS reset.
- Used CSS Flexbox for the navigation menu and CSS Grid for the services page.
- Implemented responsive design using media queries for desktop, tablet, and mobile.
